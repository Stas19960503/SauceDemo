# SauceDemo Test Checklist

## Authentication Page (authPage)
- [ ] Успешный вход с валидными данными (standard_user)
- [ ] Вход с неверным паролем (ошибка)
- [ ] Вход с заблокированным пользователем (locked_out_user)
- [ ] Вход с пустыми полями (ошибка)

## Inventory Page (inventoryPage)
- [ ] Отображение списка товаров (6 штук)
- [ ] Добавление товара в корзину
- [ ] Удаление товара из корзины (кнопка Remove)
- [ ] Сортировка товаров по цене (Low to High)
- [ ] Переход в корзину

## Cart Page (cartPage)
- [ ] Отображение добавленного товара
- [ ] Удаление товара из корзины
- [ ] Переход к оформлению заказа (Checkout)

## Page Object Pattern

В проекте реализован паттерн Page Object:
- `AuthPage` — описывает страницу логина (поля ввода, кнопка входа).
- `InventoryPage` — описывает страницу товаров (получение имени/цены, добавление в корзину, переход в корзину).
- `CartPage` — описывает страницу корзины (получение имени/цены товара).

Это позволяет отделить логику тестов от локаторов и переиспользовать код страниц в разных тестах.
